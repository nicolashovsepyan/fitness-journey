# images/ — the pictures the app shows

Mixed: some of this is finished artwork, some of it is generated, some of it
is old and unused. The parts that matter:

| | |
|---|---|
| `exercises/` | **GENERATED** — the exercise photos, cropped and shrunk from `EXERCISE LIBRARY` by `tools/build-exercise-images.mjs`. Do not edit; replace the source instead. |
| `avatars/` | **GENERATED** — the body-shape figures, sliced out of your sheets by `tools/build-avatars.mjs`. |
| `equipment/` | The kettlebell and plate pictures the gauge uses. |
| `sections/` | Card backgrounds. |
| `logo-mark.svg` · `stamp-triangle.svg` · `stamp-dumbbell.svg` | **GENERATED** by `tools/build-logo.mjs` from `logo/mark.mjs`. |
| `PRODUCTION_BRIEF.md` | the brief the artwork was commissioned from |

Everything else at the top of this folder — `day-*.png`, `conditioning*.png`,
`dips*.png`, `pull-up.png`, `Core.png` and so on — is early full-size artwork
from before the app used the generated versions. Several are 2–3 MB each. They
are still here because nothing has confirmed they are finished with. Say the
word and they go to `ARCHIVE/`.
