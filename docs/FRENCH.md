# French (France) for Fitness Journey — the reference

Every French word in the app comes from this sheet. Researched 4 Oct 2026
against French CrossFit boxes, Decathlon Conseil, Nike Training Club FR,
FizzUp, SmartWOD FR, nocsy.fr, La French Co, running media (FFA vocabulary).
**France French, not Québec.** Coach pages (labs, console) stay in English.

## Rules

- **Tutoiement everywhere** ("tu"), UI and voice. Never mix with "vous".
- **CrossFit format names stay English:** AMRAP, EMOM, For Time, Tabata, Death By, time cap.
- **France, not Québec:** fractionné (not "entraînement par intervalles"), relevés de buste (not "redressements assis"), dips (not "trempettes"), jumping jacks (not "sauts en étoile"), pompes in running text.
- **No literal translations nobody uses:** keep mountain climbers, wall ball, HSPU in English.
- **Numbers:** kg by default ("20 kg", non-breaking space), decimal comma ("2,5 kg"), thousands with a narrow space ("1 250 kg"). Time: "1:30" on the big display, "1 min 30" / "20 s" in text, the voice says "une minute trente". Reps: "reps" on chips, "répétitions" in sentences, never "rép.". Count aloud masculine: un, deux, trois.
- **Typography:** a non-breaking space before ! ? : ; — and exclamation marks sparingly.
- A workout is a **séance**.

## Exercise names

Keep the English root where France does (squat, burpee, swing, thrust, muscle-up, lever, L-sit, CrossFit names); translate the classic gym lifts the French way (développé…, soulevé…, rowing…, tirage…, élévations…). Descriptors as suffixes:

- Archer → archer
- Assisted → assisté(e)s
- Band-assisted → avec élastique
- Weighted → lesté(e)s
- Ring → aux anneaux
- Deficit → en déficit
- Tempo → tempo
- Single-arm → à un bras
- Single-leg → sur une jambe
- Dumbbell → haltère(s)
- Barbell → barre
- Incline / decline → incliné / décliné
