# Voice script: Nico's coach voice for the Training Timer

The timer says a small, fixed set of things, so the coach voice is
recorded once, as pieces, and the app plays them back. Anything not
recorded (a move nobody recorded yet) falls back to the phone's own voice.

## How to record

- **One take per section, one long recording.** Read each line, pause about
  **1 second**, read the next. Don't stop the recording between lines. I cut
  it into pieces on the pauses.
- **Phone Voice Memos is enough.** A quiet room with soft things around
  (a closet full of clothes is ideal). Phone about 20 cm from your mouth,
  same spot every time.
- **Coach energy, not announcer energy.** Clear and calm for instructions,
  a bit of push on "Go", "Last round", "10 seconds".
- **Say each line the same way every time.** The pieces get joined, so a
  flat, even delivery joins better than a dramatic one.
- If you flub one, pause, and just say it again. I keep the last take.
- Send me the files (AirDrop or Dropbox, any format).

## Section 1: numbers (counting and countdowns)

Read straight through, a short pause after each.

1 to 100: "One. Two. Three. … One hundred."


## How it gets joined (for reference)

| The app says | Built from |
|---|---|
| "Rest. Next, Burpees." | Rest. + Next. + Burpees. |
| "Round 5." | Round. + 5 |
| "12 Push-ups." | 12 + Push-ups. |
| "Last round. Burpees." | Last round. + Burpees. |
| "8 rounds. Strong work." | 8 + Rounds. + Strong work. |
| Push-up test count | 1, 2, 3 … |
