# Script vocal FR — le coach en français (France)

Same as the English recordings: one long Voice Memos recording per section,
a 1-second pause between lines, the same quiet room, phone a hand away.
**Tutoiement throughout.** Say it the way a coach in a box in Paris would:
natural, warm, not a brochure. A line not recorded is simply never said
(the robot never fills in). Sections 1 to 4 are the essentials; the rest
makes it sound alive.
