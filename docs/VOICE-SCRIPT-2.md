# Voice script 2: full sentences, variety, cues

Full sentences sound like you; joined pieces sound like a machine. Every
line below is said by the timer exactly as written, and **the app picks a
random one of the versions you record**, so it never sounds the same twice.
Record any you like, skip any you don't: a line not recorded is simply not
said (the robot never fills in).

Same as last time: one long recording per section, a 1-second pause between
lines, same room and distance. A soft room (closet, duvet) beats any echo
removal. Say them like you would in the gym, each one its own sentence.
