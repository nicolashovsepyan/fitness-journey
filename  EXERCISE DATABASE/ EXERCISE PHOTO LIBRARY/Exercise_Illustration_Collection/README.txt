EXERCISE ILLUSTRATION COLLECTION

This package contains 53 catalog entries organized into six focus-area folders.
Files are numbered to match the movement catalog and use descriptive filenames.

The forearm-plank and high-plank entries intentionally use the same combined
two-position illustration because both variations were approved together in one image.

Folders:
01 Pulling, Back and Hanging
02 Pushing, Chest and Shoulders
03 Lower Body, Glutes and Posterior Chain
04 Core and Trunk Stability
05 Power, Conditioning and Loaded Complexes
06 Mobility and Movement Control

All included files are the latest completed or corrected exports available for
their respective movements.
